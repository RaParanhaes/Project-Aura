## Documentation classes

- **Architecture** — how the accepted system is shaped.
- **ADR** — durable accepted decision.
- **RFC** — proposal still being evaluated.
- **Research** — evidence, references and open questions.
- **Roadmap** — milestones and sequencing.
- **Reference** — facts/contracts/compatibility.
- **Engineering** — quality, coverage and operational practices.
