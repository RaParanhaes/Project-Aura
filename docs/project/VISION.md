# Project AURA Vision

AURA is a platform for persistent autonomous residents in a virtual hotel.

The long-term target is a population of believable residents that connect to Polaris through normal user protocol sessions, maintain continuity over time, develop relationships and knowledge, pursue goals, learn reusable procedures and use an LLM only when reasoning or language is genuinely needed.

## What AURA is

- A headless multi-session client platform.
- A durable runtime for resident continuity.
- A semantic bridge between game events/actions and higher-level agent behavior.
- A future host for perception, memory, goals, skills, social behavior and LLM reasoning.

## What AURA is not

- A replacement for Polaris.
- A renderer/client UI for humans.
- A collection of Polaris-internal bots.
- A system where an LLM directly sends arbitrary packets or writes to the game database.
- A simulation that invents world truth independently of Polaris.

## Long-term success

A resident should be able to disconnect/reconnect, remember who it is and what it was trying to do, perceive only relevant parts of the world, act through valid game capabilities and behave differently from other residents because of its own history/state rather than a single global prompt.
