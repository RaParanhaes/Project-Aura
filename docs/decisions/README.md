# Architecture Decision Records

ADRs contain durable accepted decisions. Research/RFCs do not override accepted ADRs.

## Status values

- Proposed
- Accepted
- Superseded
- Deprecated

## Rules

- Keep ADRs short and focused.
- Record context, decision and consequences.
- Do not silently edit history to reverse an accepted decision.
- A later ADR supersedes an earlier one when architecture changes.
