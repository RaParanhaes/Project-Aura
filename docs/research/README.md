# Research Notes

Research records evidence, external implementations, experiments and open questions. It is intentionally lower authority than accepted architecture decisions.

Use a research note when investigating a project/approach. Include:

- question;
- sources/repository/version;
- findings;
- license/reuse status where relevant;
- conclusion;
- confidence (`CONFIRMED`, `LIKELY`, `RESEARCH`, `UNKNOWN`);
- impact on AURA;
- open questions.

A finding becomes an AURA architectural rule only through an accepted ADR.
