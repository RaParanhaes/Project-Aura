# Development Agent Skills

This directory will contain task-specific guidance for coding agents working on Project AURA.

Skills are loaded only when relevant so agents do not waste context reading every procedure for every task.

Planned first skills:
- `aura-preflight/`
- `polaris-protocol/`
- `implement-capability/`
- `debug-session/`
- `session-recovery/`
- `write-adr/`
- `update-documentation/`

The root `AGENTS.md` is always-on guidance; files under `.agents/skills/` are progressive, task-specific guidance.
